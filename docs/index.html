Tell it what to do. It plays the game.

Cortex is a Mac app that plays single-player games for you, from farming sims to 3D sandboxes. You type an assignment in plain English, such as harvest everything, then water the crops or gather wood and build a small hut. It watches the screen and plays with human-like keyboard and mouse input.

Download for Mac Try an assignment View the code

Apple Silicon · macOS 13 or later · free and open source

Plays almost any game

Cortex picks one of two ways to play, depending on the game.

Fast mode for 2D tile games

In top-down games like Stardew Valley, a vision model labels every tile on screen in milliseconds, and the bot walks, waters and harvests as fast as a person.

Thinking mode for any game, even 3D

Claude looks at the screen and plays: it walks, turns the camera, clicks and remembers progress. Each decision takes a few seconds, and it runs several actions per decision so the game keeps moving.

Instant reflexes

While Claude thinks, local reflexes watch for dangers like a nearly empty health bar and react within milliseconds.

Add a game in one click

Open the game and choose Add a game…. Claude looks at it and writes down its controls, useful tips and what to watch out for. You can edit all of it.

Give it an assignment

Type what you want done and see the plan Cortex would follow. The demo below uses Cortex's offline keyword parser. The app itself sends your words to Claude first, so it understands much looser phrasing.

How fast mode works

      
In 2D tile games, Claude only reads your assignment, once, before the game starts. Everything after
        that runs in a fast local loop, so the bot reacts like a person at the keyboard.

      

        

          
1 · Capture

          
Watch the game

          
Grabs the game window many times a second using macOS screen capture.

          ~8 ms
        

        

          
2 · Perceive

          
Understand the screen

          
Cuts the screen into tiles and labels each one by comparing it with descriptions like
            a sprout on dry soil using MobileCLIP. Tiles it has already seen are remembered.

          ~2 ms once the cache is warm
        

        

          
3 · Plan

          
Pick the next job

          
Follows your assignment step by step, then finds the shortest walk to the nearest crop, weed or rock.

          <1 ms
        

        

          
4 · Act

          
Play like a human

          
Holds movement keys, picks the right tool and clicks the tile, with small random timing so input looks natural.

          ~1 ms
        

      


      

        

          
No training data

          
To teach Cortex something new, you add a sentence to the game profile. CLIP matches images to text without any training.

        

        

          
Understands what you mean

          
Claude turns smash three rocks then water into exact steps, and tells you which parts it can't do. Without an API key it uses keyword matching.

        

        

          
Always under your control

          
F12 stops the bot and F11 pauses it. It also pauses when you switch windows, and stops when energy runs low or the job is done.

        

      

    

  


  

    

      

        
Get started on macOS

        
    
          
  1. Download Cortex.dmg, open it and drag
            Cortex into Applications.
    2. 
          
  2. Open Cortex. A 🌱 appears in the menu bar. If macOS says it can't verify the app, open
            System Settings → Privacy & Security and click Open Anyway.
    3. 
          
  3. Click 🌱 → Setup…. Allow Screen Recording, Accessibility and Input Monitoring, then paste your
            Claude API key. It is stored in your Keychain.
    4. 
          
  4. Pick a game, or open one and choose Add a game…. Type an assignment, press Start, then switch
            to the game. F12 stops Cortex at any time.
    5. 
        

      

      
# or, for developers: run from source
git clone https://github.com/Joto3D/Cortex
cd Cortex
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[all]"

# menu-bar app
python -m cortex.app

# or the terminal
cortex-games add "Minecraft"
cortex --game minecraft -a "gather wood"
cortex -a "harvest, then water"   # Stardew

    

  


  

    

      

        
Single-player only

        
Use Cortex only in single-player or offline games. Botting in online games usually breaks their
          Terms of Service and can get your account banned.
