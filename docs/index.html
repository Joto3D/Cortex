What it does

Plays almost any game

Cortex picks the right way to play for each game, so there's nothing to configure.

Teach it any game, no key

Press Record, play for a few minutes, then press F12. Cortex repeats what you showed it, in any game, entirely on your Mac. No API key and no extra downloads.

Plain-English assignments

Type what you want done, like break 5 rocks, then water or the name of a skill you taught. Cortex turns it into steps and tells you if something isn't possible.

Fast mode for 2D games

In top-down tile games like Stardew Valley, a vision model reads every tile in milliseconds, so the bot walks, waters and harvests at human speed.

Optional: thinking mode

With a Claude API key, Claude can look at the screen and play games it has never seen, working out new situations by itself. It takes a few seconds per decision.

Add a game in one click

Open any game and choose Add a game…, then teach it. With an API key, Claude also writes down the game's controls, tips and dangers to watch for.

You stay in control

F12 stops Cortex and F11 pauses it. It also pauses when you switch windows, and it stops at a spending limit you set.

Install in four steps

      

        

          
1

          
Drag to Applications

          
Open Cortex.dmg and drag Cortex into the Applications folder.

        

        

          
2

          
Open it the first time

          
Open Cortex. If macOS blocks it, go to System Settings → Privacy & Security and click Open Anyway.

        

        

          
3

          
Follow the setup

          
A 🌱 appears in the menu bar and setup starts. Allow Screen Recording, Accessibility and Input Monitoring. An API key is optional.

        

        

          
4

          
Play

          
Pick a game and an assignment, press Start (⌘S) and switch to the game. F12 stops it.

        

      

      
Why the "Open Anyway" step? Apple only skips that warning for apps signed with a paid developer
        account. Cortex isn't signed yet. Its code is public on GitHub, and every
        download is built from it automatically.

    

  


  

    

      
Under the hood

      
How fast mode keeps up

      
In 2D tile games, Claude reads your assignment once, before the game starts. Everything after that runs on
        your Mac in a tight loop.

      

        
1 · Capture
Watch the game
Grabs the game window many times a second.
~8 ms

        
2 · Perceive
Understand the screen
MobileCLIP labels each tile from descriptions like a sprout on dry soil. Tiles it has already seen are remembered.
~2 ms warm

        
3 · Plan
Pick the next job
Follows your assignment step by step and finds the shortest walk to the next target.
<1 ms

        
4 · Act
Play like a human
Holds movement keys, picks the tool and clicks, with small random timing.
~1 ms

      

    

  


  

    

      
Questions

      
Good to know

      

        

          Which games does it work with?
          
Any game that runs in a window on your Mac. Stardew Valley is built in with a fast mode. For any other game, add it
            from the menu and teach it by showing: record yourself playing and Cortex repeats it, with no API key. With a
            Claude API key you can also use thinking mode, which works out new situations on its own.

        

        

          How much does the Claude API cost?
          
Understanding an assignment is one small request, a fraction of a cent. In thinking mode each decision is one
            request, roughly 1–3¢. Every game has a spending limit (default $3 per run), and Cortex stops when it's reached.

        

        

          What leaves my Mac?
          
Without an API key, nothing leaves your Mac. Recordings and skills stay in your Library folder, and Cortex only
            records while the game window is in front. With a key, your assignment text goes to Claude, and in thinking mode
            screenshots of the game window do too. Your API key is stored in the macOS Keychain.

        

        

          Why does it need those permissions?
          
Screen Recording lets it see the game window. Accessibility lets it press keys and move the mouse.
            Input Monitoring makes the F12 stop and F11 pause keys work from inside the game.

        

        

          Can I use it in online games?
          
Please don't. Bots break the rules of most online games and can get your account banned. Cortex is made for
            single-player and offline play.

        

        

          Something went wrong. Where can I look?
          
Choose Show log in the Cortex menu. Then open an issue
            with what happened and the end of the log.
